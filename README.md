# Hi, I'm Carlos
<a href="https://www.linkedin.com/in/carlosmeyreles/"><img src="https://img.shields.io/badge/-LinkedIn-0072b1?&style=for-the-badge&logo=linkedin&logoColor=white" /></a>

I'm a cloud security engineer focused on cloud security architecture, security data engineering, detection engineering, and AI security. I design and build detection and response systems across GCP, AWS, and Azure, with a strong bias toward automation, least privilege, and infrastructure as code. My technical depth spans log routing and telemetry pipelines, OCSF data modeling, Terraform-provisioned infrastructure, and detection logic written in Python, KQL, and SPL.

With a foundation in cybersecurity, psychology, and business, I bring a well-rounded perspective to modern security challenges. I hold a B.S. in Cybersecurity and Information Assurance from Western Governors University and a B.A. in Psychology with a Business Management concentration from Binghamton University.

My certifications include the Google Professional Security Operations Engineer, Cribl Stream and Edge Admin, Microsoft SC-200, ISC2 SSCP, and CompTIA Security+, CySA+, PenTest+, and Network+. I care about continuous learning, mentoring, and helping organizations build resilient, threat-informed security operations. If you want to connect or talk cloud security, reach me at carlosmeyreles21@gmail.com.

## Objective

I build and secure cloud-native detection and response systems. My strengths sit at the intersection of detection engineering, security data pipelines, and cloud security architecture: routing and normalizing multi-source telemetry to the OCSF schema, provisioning infrastructure as code with Terraform, and turning raw logs into high-fidelity, low-noise detections. This page collects the hands-on projects and labs behind that work, from a Terraform-provisioned GCP detection pipeline to AWS IAM and S3 hardening labs. Each one is built to be production-minded: scoped, documented, and honest about its trade-offs.
